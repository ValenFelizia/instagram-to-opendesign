# Synthetic consumer-neutral selected brief

Start at `BRIEF.md`, then inspect `design-brief.json`, `ACCESSIBILITY.md` and the referenced assets, evidence and sources. This fixture contains an invented studio, reviewer, approvals and procedural images. It makes no claim about a real brand or the quality of generated artwork.

The custom `craft-ink` and `craft-paper` rules demonstrate core token names independent of OpenDesign slots. There is no `manifest.json`, catalog metadata or `tokens.css`, and no OpenDesign runtime is needed to read this bundle. All source and asset paths resolve inside this directory; tests verify recorded hashes.

It was compiled from the public synthetic profile/brief helpers with human-imported directions and no live provider calls. The declared solid-color pair is checked; contextual alternatives, reading order, small-screen legibility and the real native publishing action remain acceptance tasks. Request assets not chosen by the selected direction stay in the request history; only selected originals are executable artwork inputs.

OpenDesign packaging requires an explicit reviewed mapping for these custom token names. This fixture must not be presented as an installable OpenDesign design system. See [the boundary contract](../../docs/core-and-adapters.md).
