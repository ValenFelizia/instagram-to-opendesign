# Code of conduct

This is a short project policy modeled on [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The canonical text is at that link if this summary is ambiguous.

## Expected behavior

- Discuss the work, not the person. Critique the change, the evidence or the tradeoff.
- Assume a contributor read the documentation you are about to cite.
- Accept that maintainer time is limited. A slow reply is not a rejection.
- Respect privacy. Never publish another person's profile data, credentials or private project material.
- Keep the repository a place where a newcomer can ask a basic question without being mocked.

## Unacceptable behavior

- Harassment, insults, slurs or sexualized attention.
- Publishing private information without explicit permission.
- Sustained disruption of issues, pull requests or reviews.
- Retaliation against someone who reports a problem in good faith.

## Scope

This policy applies to issues, pull requests, reviews, discussions and any other project space. It also applies when someone represents the project elsewhere.

## Reporting

Report a problem to **valentinfelizia@gmail.com**. Include links or screenshots where possible. Reports are handled privately.

The maintainer will acknowledge a report, decide whether the policy was violated and choose a response. Responses range from a private warning, through a temporary restriction on participation, to a permanent ban. A maintainer involved in the incident steps aside from that decision.
