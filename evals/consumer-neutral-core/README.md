# consumer-neutral-core

**Property.** The core produces a complete, verifiable agent handoff without depending on any renderer's contract.

## Why this case exists

[DEC-009](../../.csdd/decisions.md) separates canonical preparation from the OpenDesign adapter: a renderer's fixed slots must not decide which brand facts the core can retain. Nothing in the test suite would notice if a manifest field, a catalog status or a token slot migrated back into the core, because every existing test would still pass.

This case is the tripwire. It builds a brand whose confirmed tokens have no OpenDesign slot, compiles a selected brief, exports the handoff, and requires the generated bytes to match the public example in [`examples/consumer-neutral-brief/`](../../examples/consumer-neutral-brief/).

The example is not decoration. It is the recorded output of this case, which is why it is safe to publish.

## What it runs

1. A synthetic profile, assets and analysis with fixed timestamps. No provider call.
2. Two core tokens, `craft-ink` and `craft-paper`, that OpenDesign's 56 slots cannot express.
3. A selected Instagram Story direction, exact copy and one accessibility pair.
4. `compileBrief`, then `exportAgentHandoff` twice over the same case.
5. A byte comparison against the committed example, a neutrality scan and an inventory check.

```bash
node evals/consumer-neutral-core/run.mjs
```

`pnpm test` runs the same code through `test/eval-consumer-neutral-core.test.js`.

## Reading the result

| Field | Meaning |
| --- | --- |
| `matchesCommittedExample` | Every generated byte still equals the recorded example |
| `leaks` | An adapter contract reached the core output; this must stay empty |
| `reproducible` | Two exports of the same case produced the same inventory |
| `authored` | Files the example adds by hand; only `README.md` |

## What it does not prove

- **That a creative agent does good work from this handoff.** That is the judgment layer in `outcome.md`, and it is not automated.
- **That the OpenDesign adapter works.** This case is the adapter-free path. The adapter has its own evidence in [`docs/opendesign-handoff.md`](../../docs/opendesign-handoff.md).
- **That the fixture resembles a real brand.** It is synthetic by construction. A real case lives in `evals/private/`, which is Git-ignored.
- **That the output is publishable.** A verified inventory is not human acceptance.
